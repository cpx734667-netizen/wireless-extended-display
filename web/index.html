无线扩展屏 · 网页端

通过本页桥接服务与安卓端「整屏镜像」协议互通（TCP 9000）。需电脑 Chrome/Edge 浏览器，同一 Wi-Fi 网络。
当前浏览器不支持 WebCodecs（需要电脑版 Chrome / Edge 99+）。iOS Safari 无法在此页收发画面，请用其他端投屏。

用法
① 电脑上先运行 bridge.py（或用打包的 bridge.exe）；
② 接收：手机/另一台电脑的发射端把目标 IP 填这台电脑的 IP、端口 9000，画面即出现在网页；
③ 发送：点「选择屏幕并投屏」，允许分享后，画面即投到安卓端「整屏镜像」。
